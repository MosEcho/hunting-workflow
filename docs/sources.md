# 来源、核查日期与适用范围

本仓库以重新编写的方法总结、通用代码和合成夹具实现工作流，没有打包原始案例或第三方资料全文。

| 来源 | 用途 | 本次状态 |
|---|---|---|
| [CNNVD 规范文档入口](https://www.cnnvd.org.cn/#/frontend/specDocDownload) | 用户手册、API 和产品描述资料的官方入口 | 2026-10-17 入口可达，工具未取得可解析的当前表单正文 |
| [CNNVD FAQ](https://www.cnnvd.org.cn/#/frontend/answer) | 核对平台解释 | 同上；具体条款应人工核查 |
| [CNNVD 通用型报送入口](https://www.cnnvd.org.cn/#/backend/generalSend) | 人工核对当前字段、校验与附件设置 | 首版未登录、未提交 |
| [GitHub Python CI 文档](https://docs.github.com/en/actions/tutorials/build-and-test-code/python) | 配置 Python CI | 2026-10-17 查阅；实际工作流见仓库配置 |
| [GitHub 模板仓库文档](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-template-repository) | 复用仓库布局 | 2026-10-17 查阅 |

平台配置是**本地草稿建议**，没有将社区发证经验提升为官方硬条件。
平台字段、字数、附件形式、个人/单位权限以及评级与证明条件可能变化，提交时需重新确认。
`reviewed_on` 是项目维护者检查资料入口的日期，不等于官方规则发布日期，也不等于已核实全部页面。

欢迎提交带原始来源、日期、适用页面和可复核差异的修订；涉及账号信息的截图请只在私密渠道处理。
