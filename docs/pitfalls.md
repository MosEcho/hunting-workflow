# 常见误区与检查方法

| 误区 | 更可靠的检查 | 应保留什么 |
|---|---|---|
| HTTP 200 就是绕过成功 | 比较业务语义、身份和预期权限 | 原始请求响应与正常/异常对照 |
| 标题相同就是同产品同版本 | 核对产品、组件、版本与部署特征 | 产品来源与版本证据 |
| 多个 IP 就是多个单位 | 单独核实组织归属和部署关系 | 原始实例与组织声明，不强行换算 |
| 输入行数就是受影响实例数 | 分开统计服务、版本可能影响和实际验证 | 每个实例的独立验证引用 |
| 查不到记录就证明原创 | 比较根因、版本、端点、条件和修复 | 多源查询与人工比较意见 |
| 某类漏洞必然高危 | 说明身份、可达能力、权限边界和实际影响 | 自评依据、环境条件与限制 |
| AI 找到了就可报送 | 独立人工复核关键步骤与证据 | 人工验证结果和未能确认项 |
| 报告生成了就材料齐了 | 检查版本、原文、截图、修复与当前字段 | 缺项清单与材料版本 |
| 文本解码后的响应等于原始字节 | 确认压缩、编码及存储通道 | 原始文件、摘要、必要的派生过程 |
| 复制一份就是独立历史备份 | 核对链接、共享主文件与文件字节 | 实体快照或内容清单与变更说明 |

这些是研究质量控制方法，不是任何平台的受理或评级承诺。
