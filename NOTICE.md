# Provenance and third-party materials

This repository contains newly written workflow code, method summaries and synthetic fixtures.
It distills recurring problems in personal vulnerability research and report preparation into reusable input/output contracts.
No real case archive, unpublished vulnerability report, original captured traffic, browser profile, credential or private account screenshot is bundled.

External platforms and projects are referenced through links in the documentation.
Their source code, articles, official PDFs, product images and licenses are not redistributed as part of this project.
ARTEX and space-mapping services are optional external sources of exports; this release does not require or bundle them.
